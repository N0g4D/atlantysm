# Phase 1: MUD Initialization & Setup
**Goal:** Inizializzare l'ambiente MUD per Atlantysm e verificare che compili.
**Constraints:**
1. Crea l'app in una subdirectory (es. `pnpm create mud@latest contracts --template vanilla`).
2. Assicurati che Foundry (`forge`) funzioni correttamente.
3. NON scrivere alcun contratto di gioco (nessuna tabella, nessun system).
4. Termina eseguendo `pnpm build` e assicurandoti che l'output sia pulito.
